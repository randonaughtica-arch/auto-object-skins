# Auto Object Skins

Automatically turn a level's **block decoration** into **custom objects** you can place in your own levels.

The mod looks for blocks (and slopes) with decoration attached, finds the combos that repeat throughout the level, and saves each one to the editor's <cg>Custom Objects</c> tab.

## Where to find it
- **In the editor:** the <cy>block set</c> button next to the pause button scans the level you're editing.
- **On a level's page:** the same button scans that level without opening the editor.

## Notes
- Online levels can only be scanned if they're **free to copy** (or yours), and they need to be downloaded first.
- Colors use the color channel IDs from the original level, so set up matching colors in your level.
- Tweak how sets are detected in the mod's settings.
